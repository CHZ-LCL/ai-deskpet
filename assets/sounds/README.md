# 内置音效

这个目录用于放置随插件分发的默认音效，文件名即槽位名：

| 文件 | 场景 |
| --- | --- |
| `click.mp3` | 点击桌宠 |
| `happy.mp3` | 开心 / 保存成功 |
| `alert.mp3` | 提醒 / 报错 |
| `error.mp3` | 出错 |
| `switch.mp3` | 切换形象 |

支持 `.mp3` / `.wav` / `.ogg`。**没有放文件时插件会自动用 WebAudio 合成音效**，
所以空目录也能正常工作。把音效放进这里后重新打包（或在「音效库」里导入）即可生效。

建议音量归一化到 -18 LUFS 左右，时长控制在 0.1~0.6 秒，避免点击时拖沓。
