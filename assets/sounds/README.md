# 内置音效

这个目录用于放置随插件分发的默认音效，文件名即槽位名：

| 文件 | 场景 | 当前 |
| --- | --- | --- |
| `click.mp3` | 点击桌宠 | ✅ 已附带金属管敲击声 |
| `happy.mp3` | 开心 / 保存成功 | 未提供，使用合成音 |
| `alert.mp3` | 提醒 / 报错 | 未提供，使用合成音 |
| `error.mp3` | 出错 | 未提供，使用合成音 |
| `switch.mp3` | 切换形象 | 未提供，使用合成音 |

支持 `.mp3` / `.wav` / `.ogg`。**没有放文件时插件会自动用 WebAudio 合成音效**，
所以空目录也能正常工作。把音效放进这里后重新打包即可生效；
临时替换也可以直接在「音效库」里导入。

建议音量归一化到 -18 LUFS 左右，时长短一点更跟手；`click.mp3` 是完整的敲击声（约 2 秒），
如果你想要更干脆的点击反馈，可以换成 0.1~0.3 秒的短音效。
